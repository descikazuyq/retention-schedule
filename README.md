# 本地保管期限与销毁清册

这是一个在本机运行的档案保管期限与销毁清册程序。调用者选择一个本地保存位置后，可以登记档案、记录冻结、办理解除、办理销毁，并按档案编号核对历史。程序只登记条目，不读取或保存真实文件。

所有记录保存在所选位置的单个数据文件中，关闭后重新打开同一位置，已成功办理的记录完整可查。同一位置可同时被多个本机程序打开，冻结与销毁通过文件锁串行，结果必有先后。

## 使用

```bash
go test ./...
```

```go
import "github.com/descikazuyq/retention-schedule/retention"

// 打开（或创建）一个本地保管位置。
s, err := retention.Open("/path/to/store")
defer s.Close()

// 登记档案：唯一编号、类别、起算日、保管截止日（均为 YYYY-MM-DD）。
err = s.Register("A001", "会计档案", "2024-01-01", "2024-12-31")

// 记录冻结：冻结编号在同一档案内唯一。
err = s.Freeze("A001", "F1", "诉讼保全", "2024-06-01")

// 解除冻结：解除日期不能早于冻结日期，原因必填。
err = s.Unfreeze("A001", "F1", "诉讼结束", "2024-08-01")

// 办理销毁：一次可选择多个档案，填写处理日期与唯一申请编号。
// 名单为空、编号重复、任一档案不存在/未到期/已销毁/有未解除冻结，
// 整次申请失败，不留下部分销毁或清册。
inv, err := s.Destroy("APP1", "2024-12-31", "A001", "A002")

// 按档案编号核对：登记内容、全部冻结及解除历史、当前状态、对应清册。
rec, err := s.Archive("A001")

// 按申请编号查询已关闭清册。
inv, err = s.Inventory("APP1")
```

## 规则要点

- 日期统一为 `YYYY-MM-DD`，按日历日期比较，不受时区或夏令时影响；日期必须真实存在。
- 截止日当天即视为到期，提前一天不能销毁。
- 同一档案可有多条冻结，冻结编号在档案内唯一；冻结和解除原因都不能为空白。
- 任何未解除的冻结都会阻止销毁；解除一条不影响其他冻结；不存在或已解除的冻结不能解除；不存在或已销毁的档案不能新增冻结。
- 销毁成功后生成已关闭清册，内容不可更改，档案不能恢复为未销毁；同一档案不能出现在两份成功清册中。
- 已成功的申请再次提交时，申请编号、处理日期、档案集合都相同即返回原清册（名单顺序不影响判断）；沿用编号但改变日期或集合则明确失败；失败的申请在条件改变后可用同一编号再次提交。
